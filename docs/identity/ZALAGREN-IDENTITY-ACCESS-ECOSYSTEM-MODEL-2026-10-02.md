# Zalagren Identity, Access and Ecosystem Operating Model

Research reference points reviewed on 2026-10-02:
- Safaricom Single Sign-On uses a shared Safaricom identity across digital channels and its registration terms describe email, ID number, mobile number and password as account fields.
- Safaricom's M-PESA materials distinguish account authentication from KYC/registration and list accepted identity documents by use case; some M-PESA registration guidance does not accept a driving licence as the sole registration document.
- Kenya eCitizen presents multiple login paths including eCitizen login and OTP, and its Digital ID flow separates self/assisted enrollment, document scanning, face/fingerprint verification and OTP.
- Kenyan real-estate KYC products commonly separate account onboarding from tenant/investor identity verification and may use document checks and liveness.
- Kenya's ODPC states that personal data should be collected for explicit, legitimate purposes, be adequate/relevant/limited, be accurate, be retained no longer than necessary, and remain subject to data-subject rights.

## Zalagren model

Zalagren intentionally uses four distinct layers:

1. Authentication
   - email/password
   - verified email
   - verified phone
   - future passkeys/biometrics

2. Legal identity
   - legal name is canonical
   - document type is selected from National ID, Passport, Driving Licence, residence/foreigner/refugee document, or Zalagren Identity
   - national identifiers and document numbers are protected separately

3. Verification
   - submitted is not verified
   - verified means a real verification mechanism has produced evidence
   - Zalagren Identity is a platform credential, not a government identity document

4. Participation and authority
   - community membership
   - place/context
   - role/relationship
   - capability
   - authorization
   - intent/proposal
   - action/event/evidence

## Access model

A participant can create and request things immediately within their own account boundary:
- Marketplace listings
- BeatFood merchant/menu resources
- BeatRide requests/profiles
- community participation requests
- community subscription requests
- community/node proposals

Community-specific access remains pending until a real community authority establishes the relationship. Zalagren does not turn a signup into automatic property/community authority.

## TSAVO first node

TSAVO is treated as the first-node onboarding target, not as fabricated production data.

A participant can submit a TSAVO onboarding proposal with:
- community name
- node name
- requested capabilities/services
- proposal text
- optional platform plan code and seats

The record is a real pending request. It does not claim TSAVO has subscribed, approved Zalagren, or granted access until an authorized community-side process records that decision.

## Domain readiness

The Worker now exposes real authenticated persistence for:
- participation
- community join requests
- community subscription requests
- community proposals
- community onboarding proposals
- Marketplace listings
- BeatFood merchant creation
- BeatFood menu item creation
- BeatFood order requests
- BeatRide profiles
- BeatRide ride requests

External provider execution remains separate. A BeatRide request with no provider is a Zalagren coordination record, not a claim that a driver has been dispatched. A BeatFood order is a merchant/order record until acceptance, fulfillment and payment are actually connected.

## Identity document choices

Driving licence is supported as a submitted identity document type, but Zalagren does not imply that every provider or jurisdiction accepts it for KYC. Provider-specific rules remain authoritative.

Passport is supported for local and foreign participants. National ID remains supported where applicable. Residence/foreigner/refugee documents are supported as document types where lawful and useful.

Zalagren Identity is generated by Zalagren and is explicitly not a replacement for a national ID, passport, driving licence or government registry.
